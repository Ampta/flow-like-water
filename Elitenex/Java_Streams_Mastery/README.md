## 🎯 Structure of Each Problem Entry
Every single problem entry across all category files is formatted into 8 distinct parts:
1. 📄 **Interview Problem Statement** – Authentic paragraph problem formulation from real technical interviews and Online Assessments (OA).
2. 🛍️ **Real-World Intuitive Story** – Practical mental model / everyday analogy to build quick problem intuition.
3. 📥 **Input & 📤 Output** – Clear sample test inputs and expected outputs.
4. 🔍 **Interview Clues & Trigger Keywords** – Key vocabulary words to identify the underlying pattern instantly.
5. 🛠️ **Step-by-Step Strategy** – Concrete algorithmic steps for implementation.
6. ☕ **Solution 1: Normal Java** – Traditional imperative solution using loops, maps, and condition checks with code comments.
7. ⚡ **Solution 2: Java Stream API** – Declarative functional stream pipeline solution with code comments.
8. ⚖️ **Comparison & Key Takeaways** – Trade-offs between memory, performance, and code expressiveness.
