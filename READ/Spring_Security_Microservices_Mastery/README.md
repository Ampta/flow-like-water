## 🚀 Architectural Principles Summary
1. **Zero Trust Perimeter & Internal Validation**: Authenticate at the edge API Gateway, propagate tokens via Feign `RequestInterceptor`, and enforce method-level `@PreAuthorize` authorization rules.
2. **Defensive Resilience**: Never chain synchronous calls unshielded. Wrap OpenFeign clients with Resilience4j Circuit Breakers, TimeLimiters, and graceful degradation fallbacks.
3. **Database Independence**: Avoid shared databases across microservice boundaries. Maintain consistency via Saga Orchestration or event-driven choreography.
4. **Observable Systems**: Standardize on RFC 7807 `ProblemDetail`, propagate W3C Correlation IDs across HTTP headers, and expose Prometheus metrics.
5. **Modern Reactive Angular Client**: Decouple views using Angular Signals, protect routes with functional guards (`CanActivateFn`), and handle token refresh and telemetry with `HttpInterceptorFn`.
